### 🍄 Guchhi — Wild-Foraged Himalayan Ecommerce
[![Live](https://img.shields.io/badge/Live-guchhi.in-FFB400?style=flat-square&logo=shopify&logoColor=black)](https://guchhi.in/)
![Node.js](https://img.shields.io/badge/Node.js-339933?style=flat-square&logo=node.js&logoColor=white)
![TypeScript](https://img.shields.io/badge/TypeScript-3178C6?style=flat-square&logo=typescript&logoColor=white)
![PostgreSQL](https://img.shields.io/badge/PostgreSQL-4169E1?style=flat-square&logo=postgresql&logoColor=white)
![Redis](https://img.shields.io/badge/Redis-DC382D?style=flat-square&logo=redis&logoColor=white)
![Razorpay](https://img.shields.io/badge/Razorpay-02042B?style=flat-square&logo=razorpay&logoColor=3395FF)

End-to-end ecommerce platform for **wild-harvested Himalayan produce** (Guchhi Mushrooms, Himalayan Red Rice, Premium Rajma).

**Frontend:**
- Scroll-driven animated hero with Mountain Elegance design system (Playfair Display, earthy palette, glassmorphism)
- Product detail pages with provenance maps, nutritional data, and cooking guides

**Backend (Node.js/Express/TypeScript):**
- PostgreSQL 16 via Prisma ORM · Redis for checkout session caching + rate limiting
- JWT access tokens + rotating opaque refresh tokens (httpOnly cookies)
- Razorpay Orders API + HMAC-SHA256 server-side signature verification
- Guest cart with UUID persistence, automatic cart merge on login
- Cloudinary image uploads · Nodemailer SMTP · Swagger / OpenAPI 3 docs at `/api-docs`
- Dockerized with GitHub Actions CI
